# Code of conduct

Help make this project welcoming to people with different backgrounds and levels
of experience. Discuss code and ideas respectfully, explain feedback clearly,
and accept corrections without personal attacks.

Harassment, threats, discriminatory remarks, unwanted sexual attention, doxxing,
spam and deliberate disclosure of private information are not acceptable.

This applies to this repository's issues, pull requests and other project spaces.
Maintainers may edit or remove harmful content, close disruptive discussions,
or restrict participation. Decisions should be proportionate to the behavior
and prioritize the people affected.

Use GitHub's **Report abuse** action for private reports of harassment or abuse.
Do not repost private details in public reports. Technical vulnerabilities should
instead follow [SECURITY.md](SECURITY.md).
